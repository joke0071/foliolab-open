# Stressmessung außerhalb verschlüsselter Backupgrenzen

Die 10.000er-Fixture ist ausschließlich ein Belastungsprofil. Sie überschreitet vorhandene verschlüsselte Backupgrenzen; deshalb qualifiziert sie kein innerhalb aller Backupgrenzen liegendes Benutzerportfolio. Der ergänzende Lauf 41232799162 verwendet 3.000 Buchungen und echte verschlüsselte vollständige Restore-Prüfungen beider Formate. Produkt- und Verschlüsselungscode bleiben gleich. CPU4x ist keine Android-Hardwareabnahme; Prozentwerte nicht zu älteren Releases addieren.
